How I add the next case

reused every time

This is the exact loop, repeated for every new project so the site never needs a rebuild:

  1. Ship the thing. Finish a working version of the project — doesn't need to be polished, needs to work.
  2. Open the Claude Project for this portfolio. It already knows my voice, stack, and identity kit, so I only need to describe the new project in a couple of sentences.
  3. Write the three beats. Problem (what was broken or missing) → What I did (the actual build, in plain terms) → What came of it (result, number, or reaction, even a rough one).
  4. Duplicate a .ticket block in index.html, bump the LOG number, drop in the three beats and stack tags.
  5. Push to GitHub. GitHub Pages rebuilds automatically — live in under a minute.
